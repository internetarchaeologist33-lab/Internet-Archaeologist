Nokia Mobile Codes Description Notes

*#06#Displays phone IMEI number

*#0000#Shows version, date and code of the phone's
firmware

*#746025625#(*#sim0clock#) informs, whether SIM
clock (SIM card clock) can be stopped

*3370#Switches the phone to EFR
(Enhanced Full Rate)

#3370#Disables EFR and switches the phone to
default codec

*4720#Switches the phone to HR (Half Rate)only in
phones for GSM networks supporting this codec

#4720#Disables HR and switches the phone to
default codec only in phones for GSM networks
supporting this codec

#pw+mastercode+Y# Removes simlock
(with correct mastercode).
If we don't know mastercode,we can enter any
ten-digit value (for example 1234567890)
and 1-4 digits for Y to obtain information about
following locks:

- #pw+1234567890+1# Shows Provider-Lock status
- #pw+1234567890+2# Shows Network-Lock status
- #pw+1234567890+3# Shows Country-Lock status
- #pw+1234567890+4# Shows SimCard-Lock status
if "Not restricted" message is displayed,
it means that this kind of lock is not present.
Error message means, that sim-lock of this type
is active

*#92702689#(*#war0anty#)
Runs hidden 'Warranty' application, showing
information about IMEI
and production/purchase/repair dates this code
must be entered in Telephone application on
PDA side
